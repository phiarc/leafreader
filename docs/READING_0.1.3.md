# 0.1.3 阅读交互更新

- macOS 在正文区域双指横滑：向下一页方向的横向滚动翻下一页，反向翻上一页。手势有距离阈值、方向判断和惯性锁，一次滑动只翻一页；纵向 PDF 滚动、捏合缩放不被拦截。
- 进入阅读后约 3.5 秒隐藏顶部工具栏和底部进度栏；双击正文再次显示，也可双击隐藏。手机支持双击触摸。打开目录、搜索或阅读设置期间保持工具栏显示。
- 工具栏悬浮在固定阅读布局上，显示/隐藏不改变正文分页。键盘用户可用 Escape 唤出隐藏的工具栏，再按 Escape 返回书架；面板打开时 Escape 先关闭面板。
- 滑动改为短距离滑移淡入，覆盖翻页加入轻微底页移动，翻转减小倾角并使用柔和光影，时长分别为 420 / 480 / 620 ms。尊重系统减少动态效果设置；动画期间不叠加新的翻页动画。
- TXT 每个已识别章节从新页开始，上一章末尾保留余白；前言与第一章也分页。向后翻页不跨章节拼接，已访问的页面缓存边界，保持前后翻页一致；改变字号、窗口或编码后重新计算。PDF 保留文件本身的固定页，不重排 PDF 章节。

本轮不改变文件身份、云端协议、数据库结构或既有 Unicode 阅读位置。没有操作鸿蒙设备安装或调试。

## 验证

42 项自动测试通过，包括新增长短章节、前言、反向章节边界、全文无遗漏，以及横滑方向、惯性、纵向滚动和捏合过滤测试。

本机浏览器 UI 已验证：工具栏自动隐藏与双击唤出、显隐前后正文边界一致、横向滚动双向翻页、上一章末页不包含下一章标题、下一页从新章标题开始、往返翻页正文一致。检查了 1200×850 桌面与 390×844 手机宽度布局。浏览器检查不能代替鸿蒙设备触控及帧率测试。

原生工程均重新编译，提供 0.1.3 macOS 应用与 HarmonyOS HAP；未安装到手机。

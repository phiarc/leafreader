# 鸿蒙 0.1.11 底部背景衔接

0.1.10 原生安全区使用主题底色，但共享阅读页 `.reading-body::after` 仍叠加绿色径向渐变（夜色为黑色渐变），使书页边缘与底部手势区域产生色差。

本版仅移除上述两个鸿蒙阅读页渐变规则。纸白 #f9f8f4、暖纸 #f4ecd9、夜色 #242b26 与现有原生窗口/背景层一致。不改窗口全屏开关、安全区、导航、dock、正文边距、字号、行距或分页。macOS 保持 0.1.10。

验证脚本 `scripts/verify-reader-background.mjs` 在独立浏览器中读取三种主题的底边和两角实际截图像素，与原生背景常量逐一比较。鸿蒙工程编译通过；本轮未安装或调试真机。

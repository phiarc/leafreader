# 0.1.10 安全区布局修复与 macOS 正文留白

0.1.9 将鸿蒙主窗口改为全屏，导致 ArkUI 导航进入系统状态栏区域；同时网页叠加避让区高度，使页面内容产生额外偏移。浏览器预览未包含 ArkUI 导航和真实系统状态栏，无法检出该问题。

本版恢复 `setWindowLayoutFullScreen(false)`，导航、dock、Web 均保留在系统管理的内容安全区内。移除 Web 的 expandSafeArea 和向网页注入安全区数值的逻辑，恢复书架原先的 88/116 px 导航预留。只允许不参与交互的背景 Rect 延伸绘制到上下系统区；窗口与系统栏颜色按书架/阅读模式、纸白/暖纸/夜色匹配，阅读暖纸为 #f4ecd9。继续保留通知高于 dock、编码二级菜单和正文较小的内部上下留白。

macOS “阅读偏好”提供每侧 0–35% 的连续留白滑块和百分比输入框，精度 0.1%。取消 TXT 固定 740 px 纸面宽度上限，使 0% 可以利用可用宽度。正文和测量元素使用同一个比例，调整时保留起始文字位置，重新分页并取消进行中的翻页预览。设置保存在本机，PDF 缩放不受影响。

验证：68 项回归测试通过；原生 AppKit 控件测试验证设置恢复、直接输入 23.7%、滑块回调与 0/35% 边界；独立浏览器验证实际换行与分页变化、当前文字起点、重开恢复。macOS 与 HarmonyOS 编译通过。未安装或调试鸿蒙真机，浏览器验证不能证明物理系统栏和 ArkUI 导航的最终显示效果。

原生控件验证源代码：`tests/macos-preferences.swift`。正文验证脚本：`scripts/verify-margins.mjs`，使用可选 Playwright 环境和独立 Chrome 会话。`scripts/verify-ui.mjs` 的视口现在明确表示系统安全区内的网页内容，不伪造原生状态栏。

# macOS 0.1.8 持久同步连接

升级后连接或导入个人同步配置一次。之后退出重开自动恢复地址和连接码，并执行现有启动同步流程。主动“断开连接”删除连接码记录和地址。HarmonyOS 保持 0.1.7，本轮没有安装或调试设备。

## 保存方式

`apps/macos/TokenVault.swift` 使用 CryptoKit Secure Enclave P256 密钥协商、HKDF-SHA256 和 AES-256-GCM。磁盘只保存硬件封装的私钥表示、对端公钥、随机盐和认证密文，不保存明文连接码或可直接使用的软件私钥。记录路径为 `~/Library/Application Support/com.leafreader.desktop/sync-credential.v1`，目录权限 0700，文件 0600，临时文件写入并同步后原子替换。

使用默认设备绑定访问控制，不要求 userPresence/生物识别；LAContext 明确禁止交互认证，因此不会为了恢复连接弹出密码或指纹窗口。此方案避免开发期间 ad-hoc 签名变化导致旧钥匙串条目重复授权。读取成功后在进程内缓存；每次同步不重复解密。

面向当前 Apple Silicon 发行包。硬件不可用或记录损坏会返回错误，不能保存时不会假装连接已持久保存，也不退回明文存储。设备迁移需要重新连接。该方案保护静态文件，不提供对同一用户下其他非沙盒进程的应用身份隔离。旧版本进程内连接码无法自动迁移，更新后首次需要连接一次。

## 验证

运行 `bash scripts/test-macos-vault.sh`，在真实 Secure Enclave 上使用虚构连接码验证：

- 保存、读取、目录/文件权限以及文件内不包含明文连接码。
- 两个分别编译、分别 ad-hoc 签名的不同程序跨进程读取，模拟重启和更新。
- 修改记录后拒绝读取，重新连接可替换损坏记录。
- 替换连接码后新进程恢复新值；断开后新进程为空。

以上 8 个步骤通过，认证交互始终禁用。共享阅读与同步回归测试 54 项通过。未使用真实个人连接码进行 UI 重启测试。

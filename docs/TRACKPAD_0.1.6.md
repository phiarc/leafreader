# 0.1.6：距离驱动的双指翻页

原实现累计 60 像素后播放 420–620 ms 的定时动画，期间忽略输入，再用空闲间隔判断新手势。书页并不随手指运动，慢滑缺少反馈，快速连续操作也可能被当成惯性或在动画期间被丢弃。

## 新行为

- 横向手势开始后，当前页与相邻页按实际 `wheel.deltaX` 累计距离同步平移；没有先等阈值才开始动画。反向滑动会先把书页拉回原位，再进入反方向的相邻页。
- 阈值为正文宽度的 18%，限制在 48–110 CSS 像素。跨阈值即接受这一页，不等待抬手，剩余距离用 100–190 ms 的短动画完成；不足阈值抬手后以 140 ms 回弹。
- 只在完成翻页后报告新的阅读位置。预览、回弹、首尾边界的轻微弹性反馈不提交进度。
- macOS `ReaderWebView` 报告精确滚动的开始、结束和取消阶段，保持 WebKit 原有滚动方向与 delta；将物理结束事件交给 WebKit，并拦截横向手势的惯性尾部。新物理手势立即重置状态，不需要等待固定空闲窗口。
- 连续新手势会加速完成上一页剩余动画，再从已接受的位置继续；同一手势及惯性不会再提交第二页。
- 浏览器或没有阶段信息的滚轮使用短空闲检测作为回退。纵向 PDF 滚动、控制键捏合/缩放与菜单操作不被横向翻页占用。
- 横滑范围扩展到整个正文阅读区域，包括正文两侧留白。触控板统一采用跟手平移；按钮、键盘和手机触摸仍保留所选的翻页动画，关闭动画或系统减少动态效果时直接切页。
- TXT 邻页使用原有章节分页规则；PDF 离屏准备邻页，并最多缓存两张位图。缩放、调整窗口、关闭书籍等情况会取消预览和过期任务。

## 验证

54 项自动测试覆盖距离与进度、阈值即时接受、回弹、反向撤回、惯性去重、新原生手势立即生效、边界弹性及之前的存储、同步、分页等功能。

独立开发测试页 `tests/trackpad-lab.html` 使用真实 Reader 组件和项目自有样例，不连接或修改用户书架。浏览器交互检查得到：

- 输入 20 px：正文 transform 为 -20 px，相邻页可见，提交次数为 0。
- 不足阈值结束：transform 恢复，提交次数仍为 0。
- 跨阈值且未结束：TXT 提交一次；同手势再次输入不重复提交。
- 新手势反向翻页：返回原始 TXT 偏移或 PDF 页码。
- 两个连续独立手势：TXT/PDF 都提交两页，不因前一个动画尚未完成而丢失。
- PDF 第一页向前回退：仅回弹，提交次数为 0；PDF 邻页位图与双向提交正常。
- 浏览器原生横向滚动事件也能触发一次翻页，控制台未出现 PDF 运行错误。

前端类型检查、两端构建及发布内容一致性检查已完成。macOS 原生阶段转发经过编译检查；上述浏览器手势阶段由测试页驱动，不等于真实触控板的不同硬件/系统设置都已实测。没有安装或调试鸿蒙设备。

测试面板仅存在于开发测试页，不会进入生产网页或主界面。
